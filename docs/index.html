LittlePan_v2 完整文档

一、项目概述​

LittlePan_v2 是一款轻量级、易部署的外链网盘管理系统，专注于多存储后端支持与文件安全分享，能够帮助用户便捷管理各类云存储资源，并实现文件的安全外链分发。

核心优势​

  • 轻量化架构：无冗余依赖，部署简单，资源占用低
  • 多存储适配：支持本地存储及主流云存储服务商
  • 安全可控：文件加密访问、精细化权限管理
  • 拓展性强：提供完整API接口，支持第三方应用对接

二、环境要求​

环境/依赖版本/要求
PHP7.2+
Web服务器Nginx/Apache（需开启Rewrite）
数据库适配MySQL/MySQLi（安装引导自动配置）
扩展依赖cURL、fileinfo、json（PHP基础扩展）
云存储对应云服务商SDK（自动适配，无需手动安装）

三、安装部署​

1. 下载与解压​

  • 从 Releases 下载最新版本压缩包
  • 解压至Web服务器根目录（如Nginx的html目录、Apache的htdocs目录）
  • 确保服务器对解压目录有读写权限

2. 自动安装引导​

  1. 访问部署域名/IP，系统自动跳转至安装页面
  2. 按照引导完成以下配置：
    • 数据库连接（主机、端口、账号、密码、数据库名）
    • 存储方式选择（本地/ WebDav / 阿里云OSS / 腾讯云COS / 华为云OBS / 又拍云 / SAE存储）
    • 管理员账号设置（用户名、密码）
  3. 安装完成后，系统自动在/install目录生成install.lock文件，禁用重装功能（请勿删除）

3. 验证安装​

  • 访问部署域名，可看到前台文件列表页面
  • 访问/admin路径，使用管理员账号登录后台，验证功能正常

四、核心功能说明​

1. 存储管理​

1.1 本地存储​

系统默认使用本地存储，文件存储路径为file/目录，核心操作逻辑如下：

  • 文件上传：通过move_uploaded_file将临时文件移动至存储目录
  • 文件读取：通过file_get_contents读取文件内容
  • 文件删除：通过unlink删除文件
  • 大小/类型获取：通过filesize和finfo_file获取文件属性

1.2 华为云OBS存储​

系统内置OBS存储适配类（includes/lib/Storage/Obs.php），核心功能：

  • 初始化：通过AccessKey、SecretKey、Endpoint、Bucket创建OBS客户端
  • 基础操作：文件存在性校验、上传、下载、删除、元信息获取
  • 错误处理：捕获ObsException异常，记录错误信息

1.3 其他云存储​

支持阿里云OSS、腾讯云COS、又拍云、SAE存储、WebDav等，配置方式与OBS类似，均在安装引导/后台设置中完成存储参数配置即可。

2. 文件管理​

2.1 基础操作​

  • 上传：支持单文件/批量上传，可设置是否显示在首页
  • 下载：支持直接下载，可设置下载密码验证
  • 预览：图片、音频、视频文件支持在线预览
  • 管理：重命名、删除、批量操作（后台功能）

2.2 安全控制​

  • 密码保护：可为单个文件设置下载密码
  • 权限控制：后台可设置文件是否隐藏、是否允许外链
  • 防重装：install.lock文件防止恶意重装覆盖配置

3. 后台管理​

后台路径为/admin，核心功能模块：

  • 文件管理：文件列表、上传、删除、密码设置
  • 系统设置：存储方式、API开关、域名配置
  • 账号管理：管理员密码修改（暂不支持多管理员）

五、API使用指南​

1. API基础信息​

  • 接口地址：部署域名/api.php
  • 请求方式：POST（multipart/form-data）
  • 返回格式：支持json、jsonp、form（默认json）
  • 跨域支持：内置跨域处理，支持Web端调用

4. 调用示例​

4.1 cURL调用（推荐）​

<?php
// 本地文件路径
$filePath = '/path/to/local/file.jpg';
if (!file_exists($filePath)) {
    die("文件不存在: $filePath");
}

// API地址
$apiUrl = 'https://你的部署域名/api.php';

// 创建cURL句柄
$ch = curl_init();

// 构造表单数据
$postData = [
    'file' => new CURLFile($filePath),
    'format' => 'json',
    'ispwd' => 1,
    'pwd' => 'SecurePass123'
];

// 设置cURL选项
curl_setopt_array($ch, [
    CURLOPT_URL => $apiUrl,
    CURLOPT_POST => true,
    CURLOPT_POSTFIELDS => $postData,
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HEADER => false,
    CURLOPT_SSL_VERIFYPEER => true,
    CURLOPT_SSL_VERIFYHOST => 2,
    CURLOPT_TIMEOUT => 60
]);

// 执行请求
$response = curl_exec($ch);
$httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);

// 错误处理
if (curl_errno($ch)) {
    die('cURL错误: ' . curl_error($ch));
}
curl_close($ch);

// 处理响应
if ($httpCode === 200) {
    $result = json_decode($response, true);
    if ($result && $result['code'] === 0) {
        echo "上传成功！\n";
        echo "下载链接: {$result['downurl']}\n";
        echo "预览链接: {$result['viewurl']}\n";
    } else {
        echo "上传失败: {$result['msg']}\n";
    }
} else {
    echo "HTTP请求失败，状态码: $httpCode\n";
}
?>

4.2 Guzzle调用​

<?php
require 'vendor/autoload.php';

use GuzzleHttp\Client;
use GuzzleHttp\Psr7\Utils;

$filePath = '/path/to/local/file.jpg';
$apiUrl = 'https://你的部署域名/api.php';

$client = new Client();

try {
    $response = $client->post($apiUrl, [
        'multipart' => [
            [
                'name' => 'file',
                'contents' => fopen($filePath, 'r'),
                'filename' => basename($filePath)
            ],
            [
                'name' => 'format',
                'contents' => 'json'
            ],
            [
                'name' => 'ispwd',
                'contents' => '1'
            ],
            [
                'name' => 'pwd',
                'contents' => 'SecurePass123'
            ]
        ]
    ]);

    $result = json_decode($response->getBody(), true);
    if ($result && $result['code'] === 0) {
        echo "上传成功: {$result['msg']}\n";
        echo "下载链接: {$result['downurl']}\n";
    } else {
        echo "上传失败: {$result['msg']}\n";
    }
} catch (\Exception $e) {
    echo "请求异常: " . $e->getMessage() . "\n";
}
?>

5. 文件删除API​

  • 请求方式：DELETE
  • 必要参数：
    • hash：文件MD5值
    • file_pwd：文件设置的下载密码（若未设置则无需传）
  • 示例（curl）：
curl -X DELETE \
  -d "hash=3a78c73f88489c8f33c0e430683b5d5&file_pwd=123456" \
  https://你的部署域名/api.php

七、常见问题​

1. 安装后无法访问​

  • 检查Web服务器Rewrite是否开启
  • 确认目录权限（需755/775，根据服务器配置调整）
  • 检查PHP版本是否≥7.2

2. 文件上传失败​

  • 检查php.ini中upload_max_filesize、post_max_size配置
  • 确认存储目录有写入权限
  • 云存储上传失败：检查AccessKey/SecretKey/Endpoint/Bucket配置是否正确

3. API调用失败​

  • 检查API是否启用（后台系统设置）
  • 确认请求方式为POST，且Content-Type为multipart/form-data
  • 检查参数是否完整（尤其是file字段）
